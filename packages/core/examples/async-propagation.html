Traditional Complexity

Callback Hell 
fetchUser(id, (err, user) => {
  if (err) return error();
  fetchRepos(user.id, (err, repos) => {
    if (err) return error();
    getStats(repos, (err, stats) => {
      render(stats);
    });
  });
});

Atomic Declarative

Declarative 
const user = computed(async () => {
  return await fetchUser(id.value);
});

const repos = computed(async () => {
  return await fetchRepos(user.value);
});

// Errors propagate automatically!
  • Flat Architecture
  • Auto Dependency Tracking
  • Built-in Propagation

Error Awareness

When Stage 2 fails, Stage 3 detects it instantly via the hasError property. The error state flows through the recovery chain, allowing downstream consumers to enter "Blocked" or "Error" states gracefully without manual try-catch everywhere.

The Benefit

  • No more nested error handling logic
  • Uniform async state tracking across the app
  • Clear visualization of state dependency
  • Surgical updates based on async resolution
