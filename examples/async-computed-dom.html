Core Code

// 1. Reactive State
const query = atom('');

// 2. Async Computed (First-Class Support)
const results = computed(
  async () => {
    if (!query.value) return [];
    const res = await fetch(`/api/search?q=${query.value}`);
    return res.json();
  },
  { defaultValue: [] }
);

// 3. Automatic Updates
effect(() => {
  // ✨ .state, .isPending are reactive properties!
  // No need to manually track loading states
  if (results.isPending) {
    showLoading();
  } else if (results.hasError) {
    showError(results.lastError);
  } else {
    showList(results.value);
  }
});
🎯 First-Class Async Computed Features
  • Automatic State Tracking - Built-in state, isPending, isResolved properties
  • Race Condition Handling - Only latest request is applied (auto-cancellation)
  • Error Handling - hasError, lastError properties provided
  • Automatic Dependency Tracking - Works perfectly inside async functions
  • defaultValue - Specify default value for pending state
