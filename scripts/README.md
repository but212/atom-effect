# Utility Scripts

This directory contains utility scripts to automate maintenance and lifecycle tasks across the `atom-effect` monorepo.

## Benchmark Docs Updater (`update-benchmarks.js`)

The `update-benchmarks.js` script automates parsing raw Vitest benchmark execution logs and surgically updating the performance tables across all monorepo package documentations.

### How It Works

1. **Log Parsing**: Scrapes raw text outputs generated by Vitest benchmarking suites in the root workspace (`core-micro.txt`, `core-macro.txt`, etc.).
2. **Text Normalization**: Standardizes test case names to robustly match them against Markdown row keys.
3. **Dynamic Validation**: Scans Markdown tables, dynamically resolves column indexes based on header names (`Result`, `Value`, `ops/sec (Hz)`, etc.), and throws errors if table structures are invalid or mutated.
4. **Surgical In-place Editing**: Updates only the corresponding throughput (Hz), mean, and p99 cells without modifying surrounding text or formatting.

### Prerequisites

Ensure the raw benchmark logs are located at the root of the workspace:

- `core-micro.txt`
- `core-macro.txt`
- `core-realistic.txt`
- `core-state.txt`
- `jquery-macro.txt`
- `jquery-micro.txt`
- `utils-all.txt`

### Usage

Run the script from the monorepo root directory:

```bash
node scripts/update-benchmarks.js
```

### Affected Documentation Files

- **Core Package**:
  - `packages/core/docs/BENCHMARKS.md` (Overview table)
  - `packages/core/docs/BENCHMARKS_DETAILED.md` (Detailed tables)
- **jQuery Binding Package**:
  - `packages/jquery/docs/BENCHMARKS.md` (Overview and Highlights tables)
  - `packages/jquery/docs/BENCHMARKS_DETAILED.md` (Detailed tables)
- **Utility Package**:
  - `packages/utils/docs/BENCHMARKS.md` (Overview table)
