# Utility Scripts

This directory contains utility scripts to automate maintenance and lifecycle tasks across the `atom-effect` monorepo.

## Benchmark Docs Updater (`update-benchmarks.js`)

The `update-benchmarks.js` script automates parsing raw Vitest benchmark execution logs and surgically updating the performance tables across all monorepo package documentations.

### How It Works

1. **Log Parsing**: Scrapes raw text outputs generated by Vitest benchmarking suites from the workspace root or an optional input directory (`core-micro.txt`, `core-macro.txt`, etc.).
2. **Text Normalization**: Standardizes test case names to robustly match them against Markdown row keys.
3. **Dynamic Validation**: Scans Markdown tables, dynamically resolves column indexes based on header names (`Result`, `Value`, `ops/sec (Hz)`, etc.), and throws errors if table structures are invalid or mutated.
4. **Surgical In-place Editing**: Updates only the corresponding throughput (Hz), mean, and p99 cells without modifying surrounding text or formatting.

### Prerequisites

Ensure the raw benchmark logs are located at the root of the workspace, or pass the directory containing them as the first argument:

- `core-micro.txt`
- `core-macro.txt`
- `core-realistic.txt`
- `core-state.txt`
- `jquery-macro.txt`
- `jquery-micro.txt`
- `utils-all.txt`

### Usage

Run the script from the monorepo root directory:

```bash
node scripts/update-benchmarks.js
node scripts/update-benchmarks.js results-merged
```

The benchmark workflow uses the second form after downloading its raw result artifacts.

To run the focused updater validation:

```bash
node --test scripts/update-benchmarks.test.js
```

### Affected Documentation Files

- **Core Package**:
  - `packages/core/docs/BENCHMARKS.md` (Overview table)
  - `packages/core/docs/BENCHMARKS_DETAILED.md` (Detailed tables)
- **jQuery Binding Package**:
  - `packages/jquery/docs/BENCHMARKS.md` (Overview and Highlights tables)
  - `packages/jquery/docs/BENCHMARKS_DETAILED.md` (Detailed tables)
- **Utility Package**:
  - `packages/utils/docs/BENCHMARKS.md` (Overview table)
  - `packages/utils/docs/BENCHMARKS_DETAILED.md` (Detailed tables)

## Release Helper (`release-helper.js`)

The `release-helper.js` script validates package versions and extracts version-specific release notes from `CHANGELOG.md` during the release workflow.

### How It Works

1. **Version Validation**:
   - Reads the target release version from the `GITHUB_REF_NAME` environment variable (stripping the leading `v` prefix).
   - Verifies that this version matches the `version` field in the root `package.json` and in every package's `package.json` under the `packages` directory (skipping private packages).
   - Aborts and exits with an error code if there is any mismatch.
2. **Release Notes Extraction**:
   - Parses `CHANGELOG.md` and locates the section corresponding to the target version (`## [version]`).
   - Extracts the notes for that version, strips the header, and writes the contents to a new file named `RELEASE_NOTES.md`.

### Prerequisites

The environment variable `GITHUB_REF_NAME` must be set. For example:

```bash
$env:GITHUB_REF_NAME="v1.0.0"
```

### Usage

Run the script from the monorepo root directory:

```bash
node scripts/release-helper.js
```
