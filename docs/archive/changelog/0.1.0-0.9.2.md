# Changelog Archive: 0.1.0 – 0.9.2

> Moved verbatim from [CHANGELOG.md](../../../CHANGELOG.md).

## [0.9.2]

### Core

#### Changed

- **Documentation**: Performance note removed from README.md.

## [0.9.1]

### Core

#### Changed

- **Architecture**: `Scheduler` reworked for automatic group updates.
  - `_drainQueue` replaces microtask chaining.
  - Sync updates in the same tick run in one microtask cycle.
  - Removes redundant microtask scheduling and context switches.

## [0.9.0]

### Core

#### Changed

- **Debug**: Effect loop detection uses an O(1) circular buffer.
- **Internal**: Epoch system wrap-around safety check added.

#### Added

- `onError` option in `EffectOptions` for handling execution errors.

## [0.8.4]

### Changed

- **Benchmarks**: Suite reworked for fairness and accuracy.
  - Object creation lifted out of loops; static assignments replaced with toggling.
  - Added `batch()` throughput and pure Effect re-execution benchmarks.

## [0.8.3]

### Changed

- **Type Safety**: `ComputationContext` interface added for computed lifecycle typing.
- **Refactor**: Duplication between `AtomImpl` and `ComputedAtomImpl` reduced via a shared tracking utility.

## [0.8.2]

### Fixed

- **Packaging**: `publishConfig.access: public` added to `@but212/atom-effect-jquery` to fix npm "payment required" error for scoped packages.

## [0.8.1]

### Fixed

- **Packaging**: Scoped to `@but212/atom-effect-jquery` to fix npm publish permission errors.

## [0.8.0]

### Changed

- **Monorepo Migration**: pnpm workspace + Turborepo structure.
  - Root workspace manages `packages/core` and `packages/jquery`.
  - Shared `tsconfig.base.json` and `biome.json` at root.
  - Turborepo enables parallel, cache-aware builds.
- **Unified Versioning**: Both packages share one version; a single `v*` tag publishes both.
- **Binding**: Two-way binding logic extracted into `applyInputBinding`, shared by `$.fn.atomVal` and `bindVal`.
- **Infrastructure**: `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json` added.
- **CI/CD**: `ci.yml`, `benchmark.yml`, `publish.yml` updated for monorepo paths.

## [0.7.0]

### Added

- **Error Propagation**: Errors accumulate through computed chains.
  - `errors: readonly Error[]` on `ComputedAtom`: deduplicated errors from self and all dependencies.
  - `isValid: boolean`: inverse of `hasError`.
  - `hasError` propagates error state from the dependency chain.
- **Documentation**: `examples/async-propagation.html` demo of the declarative async pipeline.

### Changed

- **Reactivity**: `ComputedAtom` wraps dependency errors in `ComputedError` and returns `defaultValue` on recoverable errors.
- **Internal**: Error deduplication via internal `Set` prevents duplicate reports in diamond dependencies.

### Fixed

- **Reactivity**: Computed values throwing synchronously were not registered as parent dependencies.
- **Reactivity**: Async computed error states now propagate to downstream dependencies.

### Removed

- `ComputedStateFlags` and handler classes (`SyncComputationHandler`, `AsyncComputationHandler`).

## [0.6.0]

### Added

- **Documentation**: `examples/async-computed-dom.html` demo of async computed with vanilla DOM.

### Changed

- **Reactivity**: Async state getters (`.state`, `.hasError`, `.lastError`, `.isPending`, `.isResolved`) register dependency tracking via `_registerTracking()`.
- **Documentation**: CDN options updated to `unpkg` and `jsdelivr`.

### Fixed

- **Reactivity**: `_handleAsyncResolution` calls `_notifyJob()` after async completion so effects re-run.

## [0.5.1]

### Changed

- **Performance**: Scheduler limits relaxed for higher-frequency updates.
  - `MAX_EXECUTIONS_PER_EFFECT`: 50 → **100**
  - `MAX_EXECUTIONS_PER_SECOND`: 100 → **1000**
  - `MAX_EXECUTIONS_PER_FLUSH`: 5000 → **10000**
  - `CLEANUP_THRESHOLD`: 100 → **1000**

## [0.5.0]

### Changed

- **Refactor**: Utilities centralized in `src/utils/` (`ArrayPool`, `type-guards`, `error`).
- **Type Safety**: `DependencyId` branded type.
- **Breaking**: `batch` and `untracked` propagate original errors instead of wrapping them in `AtomError`.

## [0.4.0]

### Changed

- **Internal**: `Atom`, `Computed`, and `Effect` streamlined; unused variables and redundant type checks removed.
- **Refactor**: `_notify()` renamed `_scheduleNotification()`; `Computed` hot paths optimized.
- **Type Safety**: User-defined type guards (`hasDependencyMethod()`, `isPlainListener()`, `hasExecuteMethod()`, `isTrackableFunction()`) replace unsafe `as` assertions.

## [0.3.3]

### Added

- **Testing**: Memory and stability tests (`gc-verification`, `circular-reference`, `fuzz`).

### Changed

- **Refactor**: `pool.ts`, `epoch.ts`, `scheduler/` moved to `src/internal/`.
- **Documentation**: Excess JSDoc removed across 7 core files (~1,200 lines).

### Fixed

- `_setIdle()` in `_markDirty()` no longer clears the RESOLVED flag on computed values.

## [0.3.2] - 2026-01-09

### Changed

- **Architecture**: "Push-State, Pull-Value" propagation.
  - **Internal**: `Computed._markDirty()` propagates dirty flags synchronously without scheduler registration.
  - **Refactor**: `_recomputeJob` removed (lazy recomputation via `value` getter).
  - **Performance**: `Computed.version` changes only when the value changes (respects `equal`).

## [0.3.1] - 2026-01-09

### Changed

- **Memory**: `Map` replaced by an array for `_subscriptions` in `Computed` and `Effect`.
- **Performance**: `Set` replaced by an epoch check for `_modifiedDeps` in `Effect`.
- **Internal**: `Computed` implements `Subscriber` directly.
- **Debug**: `debug.checkCircular` uses epoch-based traversal.

## [0.3.0] - 2026-01-09

### Added

- `maxExecutionsPerFlush` in `EffectOptions` prevents infinite loops in complex graphs.

### Changed

- **Performance**: Bitwise masking applied to `Computed` and `Effect` state hot paths.

## [0.2.2] - 2026-01-08

### Changed

- README.md updated.

## [0.2.1] - 2026-01-08

### Changed

- **Performance**: `WeakMap` replaced by array-based lookup in `SubscriberManager`.

## [0.2.0] - 2026-01-04

### Changed

- **Performance**: Pooled arrays for zero-allocation dependency tracking; O(1) epoch-based dedup; V8 Smi optimization. `Computed` creation ~34% faster, `Effect` ~17%, GC pressure ~20% lower.
- **Stability**: `IDLE` → `BATCHING` → `FLUSHING` lifecycle enforced. `Computed`/`Effect` keep valid dependencies after execution failure.

### Removed

- `DependencyManager` (folded into internal logic).

## [0.1.5] - 2026-01-02

### Changed

- **Bundling**: Type definitions bundled into `index.d.ts`; `package.json` paths standardized under `./dist/`.

## [0.1.4] - 2026-01-02

### Changed

- **Performance**: Strict property init order in `ComputedAtomImpl` for V8 hidden-class monomorphism.

## [0.1.3] - 2026-01-02

### Changed

- **Performance**: "Delta Sync" (diffing) in `Effect` and `Computed` reduces subscription churn.
- **Performance**: `DependencyManager` uses strong references; `Scheduler` uses double buffering.
- **Refactor**: `AtomImpl` subscription logic replaced by `SubscriberManager`.

### Fixed

- **Reactivity**: Infinite loops from synchronous self-modification now detected (subscription was delayed).
