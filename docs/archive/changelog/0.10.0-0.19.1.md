## [0.16.0] - 2026-01-27

### Core

#### Changed

- **Performance**: V8 hidden-class stabilization, fewer property accesses, and bitwise flag consolidation.
- **Performance**: Tracking and notification loops micro-optimized to reduce stack depth and branch mispredictions.
- **Memory**: Zero-allocation array reuse (`arr.length = 0`) in `Atom`, `Computed`, and `Effect`.
- **Internal**: Scheduler buffer management and drain cycles refactored for locality and microtask efficiency.
- **Internal**: Error handlers and helpers (e.g., `_addSubscriber`) hoisted for JIT inlining.

### jQuery

#### Changed

- **Performance**: Redundant write guards (`el.textContent !== newVal`) and direct property access reduce reflows.
- **Memory**: `$.data()` replaced by `WeakMap`-based binding and debug records.
- **Refactor**: Declarative and chainable binding handlers share one context.
- **Performance**: Camel-case property cache removes repeated regex work in style updates.
- **Performance**: `atomList` attribute and path preparation optimized.
- **Debug**: Visual highlighting uses `requestAnimationFrame` and direct style changes.

## [0.15.4]

### Core

#### Fixed

- **Lazy Computed Sensitivity**: `Effect` could skip execution when a dependency was a stale `computed`. The check now forces re-evaluation of computed dependencies and re-checks their version.

## [0.15.3]

### Core

#### Added

- **Testing**: Test for circular dependencies in effects.

### jQuery

#### Fixed

- **atomList Edge Cases**:
  - **DOM Cleanup Race**: Async `onRemove` callbacks could leave ghost elements if an item was re-added synchronously. `isConnected` checks added during reconciliation.
  - **`key`**: `keyof T | (item, index) => string | number` (required). Property name or function returning a unique ID for diffing.
  - **`render`**: `(item, index) => string | Element | DocumentFragment | JQuery`. Supports multiple root elements (e.g. `<i></i><b></b>`).
  - **`bind`**: `($el, item, index) => void`. One-time reactive binding for the element.
  - **`update`**: `($el, item, index) => void`. Manual update when the key is unchanged (avoids re-binding).
  - **`onAdd`**: `($el) => void`. Called after an item is added.
  - **`onRemove`**: `($el) => Promise<void> | void`. Called before removal; supports async exit animations.
  - **`empty`**: `string | Element | DocumentFragment | JQuery`. Shown when the list is empty.
  - **`isEqual`**: `(oldItem, newItem) => boolean`. Custom equality (default: shallow).
  - **`events`**: `Record<string, (item, index, e) => void>`. Delegated handlers on the container; one listener per event type. Key format: `'eventType' or 'eventType selector'`.
  - **Modularization**:
    input-binding.ts — Two-way input binding with IME, debounce, and cursor support
    form.ts — Form binding with lens-based deep paths
    list/ — Modularized atomList implementation
    index.ts — Entry point and effect registration
    diff.ts — Keyed diffing with prefix/suffix trimming
    dom.ts — DOM manipulation, rendering, and empty state
    context.ts — ListContext for state and async removals
    types.ts — Internal types and interfaces
    mount.ts — atomMount / atomUnmount lifecycle
  - **Empty Template Typing**: TS error in empty template logic fixed.

## [0.15.2]

#### Changed

## [0.15.1]

### jQuery

#### Fixed

- **Debounce Blur Data Loss**: Blurring an input with a pending debounce no longer loses input; `onBlur` flushes pending sync operations before formatting.
- **Zombie Binding Cleanup**: Orphaned `_aes-bound` markers on cloned elements are removed by `cleanupDescendants` when no binding data exists.
- **Cursor Jumping**: Cursor position preserved when a focused input's atom updates externally.
- **State Phase Recovery**: State phase transitions wrapped in `try...finally` so `state.phase` always resets to `'idle'`.

## [0.15.0]

### Core

#### Fixed

- **Circular Dependencies**: Throws `ComputedError` instead of returning undefined.
- **Effect Errors**: `EFFECT_DISPOSED` thrown correctly; rate-limit execution flow fixed.
- **Atom Notifications**: Race where notifications flushed after disposal no longer delivers `undefined` to subscribers.
- **Async Effect Cleanup**: Stale async cleanups no longer clobber newer ones; execution ID tracking added.

#### Changed

- **Debug**: Warnings for duplicate subscriptions and mismatched batching; production checks optimized.
- **Internal**: Object pool reset improved; epoch overflow prevented; type guards simplified.
- **Reactivity**: Async drift detection uses DJB2-style bitwise hash mixing for snapshots.

#### Removed

- Unused private methods, redundant state resets, and duplicate JSDoc.
- Urgent queue and priority logic from `Scheduler`.
- `isUrgent()` and `_getAggregateShift()` from `ComputedAtomImpl`.
- Obsolete phase-shift constants (`PHASE_BITS`, `PHASE_THRESHOLD`, `PHASE_MASK`).

### jQuery

#### Fixed

- **Debug**: Cleanup error logging and registry management for detached nodes improved.

#### Changed

- **API**: Custom equality support; phase state logic unified.
- **Type Safety**: `any` in event handler and binding maps replaced with strong types.
- **Debug**: Static values trigger DOM debug events.
- **Robustness**: Duplicate-key warnings in development mode.

#### Removed

- Unused `effects` context field and redundant variables.

## [0.13.0]

### Benchmarks

- **Overhaul**: Benchmark suite re-engineered for statistical significance and low noise.
  - Micro-benchmarks batched (x1000) for better signal-to-noise.
  - Reactive graph init isolated from measurement loops.
  - Vanilla JS baselines added to macro-benchmarks.
  - Redundant micro-benchmarks merged into core suites.
  - More iterations and warmup for consistent results (< 5% CV).

### Core

#### Changed

- **Refactor**: `core/` flattened; interfaces consolidated into `src/types.ts`.
- **Refactor**: `scheduler.ts` and `batch.ts` moved to `src/internal/`; `ReactiveNode` and `ReactiveDependency` unified in `src/core/base.ts`.
- **Refactor**: Internal and test imports use `@/` path aliases.
- **Testing**: Core unit tests de-duplicated.
- **Fixed**: Path errors in `reactive_core.test.ts` resolved.

### jQuery

#### Fixed

- **Double Cleanup**: `$.fn.remove` marks elements "ignored" before removal, so `MutationObserver` doesn't trigger a second cleanup.

#### Changed

- `cleanupTree` is O(M) over bound elements only, using the `AES_BOUND` class marker with `querySelectorAll`.
- `getLIS` (longest increasing subsequence) moved to `utils.ts`.
- Test suite consolidated from 13 files to 8:
  - `mount.test.ts` + `memory.test.ts` → `lifecycle.test.ts`.
  - `keyed-diffing.test.ts` → `list.test.ts`.
  - `input.test.ts` covers all two-way bindings, IME, and focus tracking.
  - `chainable.test.ts` limited to API surface and chaining.

## [0.11.0]

### Core

#### Added

- **Discrete Phase-Shift Versioning**: 30-bit cyclic phase (10-bit cycle, 20-bit phase) for V8 Smi. `version` moved from `ReactiveDependency` to `ReactiveNode`.
- **Branchless Operations**: `rotatePhase()` for O(1) rotation; `getShift()` for O(1) modular distance.
- **Urgent Priority Queue**: Jobs past `PHASE_THRESHOLD` are prioritized.
- **Internal**: `_getAggregateShift()` tracks total staleness across dependencies.
- **Async Drift Validation**: Fail-fast drift detection (up to `MAX_ASYNC_RETRIES = 3`) prevents UI flicker from races.
