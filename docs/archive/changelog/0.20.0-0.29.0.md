# Changelog Archive: 0.20.0 – 0.29.0

> Moved verbatim from [CHANGELOG.md](../../../CHANGELOG.md).

## [0.29.0] - 2026-04-07

### Core

- **Breaking**: `maxAsyncRetries` removed from `computed`; drift now re-evaluates via `_markDirty()`.
- **Performance**: DJB2 hashing replaced by a unified `_isDirty` mechanism.
- **Internal**: Directory flattened (`internal/`, `tracking/`, `errors/` removed) into cohesive modules.

### jQuery

- **Added**: `atomForm` gains `debounce`, `transform`, `onChange`, and deep paths.
- **Changed**: Form binding reimplemented via `FormBinder` for circular protection and O(1) dispatch.
- **Internal**: Pool sets merged; test suites refactored for behavior-driven checks.

## [0.28.0] - 2026-04-03

### Core

- **Added**: Official lens support (`atomLens`, `lensFor`) with recursive dot-path types.
- **Performance**: Lens write paths use identity guards to skip redundant propagation.

### jQuery

- **Performance**: Branch-prediction optimizations: monomorphic dispatch and strategy specialization.
- **Performance**: Fast-path scanner in `sanitizeHtml` for safe strings (~5x).
- **Encapsulation**: Lens core moved into the main package; jQuery exports restricted to the `$` namespace.

## [0.27.0] - 2026-03-31

### Core

- **Performance**: Engine pass: SVO unrolling to remove closure overhead in hot loops; class-based singletons for `trackingContext` and `debug` to stabilize hidden classes; bitwise status management and local caching.

### jQuery

- **Refactor**: Overhaul removes 1,000+ lines of redundant logic via monomorphic structures.
- **Performance**: Hoisted allocations; native loops and selectors (`getElementsByClassName`).
- **Robustness**: Better error isolation in `$.route` and `atomFetch`.

## [0.26.0] - 2026-03-24

- **Core**: Infinite loop detection and exception-safe `runInFlushScope` wrappers.
- **jQuery**: `atomForm` scales O(1) on large forms.

## [0.25.0] - 2026-03-17

- **jQuery**: Native `Promise` support in content and attribute bindings; DOM metadata caching.

## [0.24.1] - 2026-03-10

- **Core**: Unified `_isDirty()` mechanism; stabilized V8 hidden classes.
- **jQuery**: Initial `$.fn.atomForm` release with nested path support.

## [0.24.0] - 2026-03-03

- **Core**: Bit-packed slot buffers and O(1) stable-skip re-evaluation.
- **jQuery**: `atomList` rewritten on a 1D flat buffer with typed arrays.

## [0.23.0]

### Core

- **Performance**: Zero-allocation O(1) stable-skip re-evaluation; engine micro-optimizations.
- **Safety**: Internal object branding hardened; generic typings refined.

### jQuery

- **Bindings**: Native `<select multiple>` support; reactive `ajaxOptions` in `atomFetch`.
- **Performance**: Monomorphic records and lightweight `nodeType` checks.

## [0.22.2]

### jQuery

- **Performance**: Native `for`/`for...in` loops replace iterators.
- **Security**: HTML sanitization hardened against protocol-bypass vectors.

## [0.22.1]

### Core

- **Stability**: Async retry logic refined; drift scenario tests expanded.

## [0.22.0]

### Core

- **Refactor**: Internal loops modernized with array methods.

### jQuery

- **Architecture**: Binding registry optimized; regex-based sanitization made faster.
- **Routing**: Router overhauled with navigation guards and abort-safe fetching.

## [0.21.3]

### jQuery

#### Added

- **Routing**: `queryParams` atom on `Router`.
- **Routing**: `onParamsChange` hook handles same-route parameter changes without a full re-render.
- **Lifecycle**: `onMount` hook for template routes exposes the rendered jQuery element.

#### Changed

- Active link tracking consolidated into one effect, reducing memory for apps with many links.
- `history.pushState`/`replaceState` failures (e.g., `file://`) log warnings via `debug` instead of throwing.

#### Security

- "Silent blocking" policy for `sanitizeHtml` and security bindings: no console warnings.

## [0.21.2]

### Core

#### Added

- **API**: `[Symbol.dispose]()` on `Atom`, `Computed`, and `Effect` for `using` support.

#### Changed

- **Tree-shaking**: Vite removes debug code in production (~6% bundle reduction).

## [0.21.1]

### Core

#### Changed

- **Naming**: `SubscriberLink` renamed to `Subscription`.
- **Reactivity**: `defaultValue` is the fallback for all error types, including non-recoverable ones.
- **Refactor**: Constants and error messages extracted to dedicated files.

#### Fixed

- **Effect Resource Leak**: Subscription cleanup fails after mid-execution errors.

### jQuery

#### Changed

- **Refactor**: Constants, log prefixes, and error messages extracted to `constants.ts`.

## [0.21.0]

### Core

#### Added

- **API**: Brand symbols for runtime type identification.
- **Internal**: Bitwise hashing for version snapshots.

#### Changed

- **Compilation**: ES2021 syntax; build targets updated.

### jQuery

#### Added

- **API**: `$.atomFetch`: declarative reactive AJAX primitive.

#### Changed

- **Routing**: Migrated to native DOM APIs.
- **Reactivity**: Checks use the new core brand symbols.

## [0.20.0]

### Core

#### Changed

- **Internal**: Epoch counters merged.
- **Performance**: `_commitDeps` and `_checkLoopWarnings` inlined.
- **Core**: Error collection streamlined; complex lookup tables removed from `Computed`.
- **Debug**: Effect loop detection uses a sliding window.
- **Performance**: Subscription reuse uses linear scanning.

#### Removed

- **Internal**: Internal type wrappers, unused object pools, and redundant properties (`timestamp`, `_modifiedAtEpoch`).

### jQuery

#### Changed

- **Binding**: Chainable methods use unified binding handlers.
- **Binding**: `atomChecked` and `bindVisibility` standardized.
- **Debug**: Equality checks centralized; debug-mode DOM access optimized.
- **Routing**: Router uses `URLSearchParams` and supports `pushState`.
- **Binding**: `bindCss` unifies array and string values.
